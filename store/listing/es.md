# Store listing — Español

## Nombre
BK Picker

## Descripción corta
Selector de color de pantalla e imagen, lupa, equivalentes Tailwind/Material/CSS/Bootstrap, HEX/RGB/HSL/OKLCH. Hecho por Adrian Tafoya.

## Descripción
BK Picker es una utilidad rápida para Windows:

- Pipeta con lupa y atajo global (Alt+C)
- Copia HEX, RGB, HSL moderno, OKLCH y HEX+alpha
- Historial, favoritos y export CSS/JSON
- Paletas complementarias, análogas y triádicas
- Equivalentes Tailwind, Material, CSS named y Bootstrap
- Contraste WCAG AA/AAA vs blanco y negro
- Muestreo desde archivo, URL, arrastrar o pegar imagen

Todo corre en local en tu PC. No sube capturas a internet.
