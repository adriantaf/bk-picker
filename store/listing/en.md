# Store listing — English

## Name
BK Picker

## Short description
Screen & image color picker with loupe, design-system matches (Tailwind, Material, CSS, Bootstrap), HEX/RGB/HSL/OKLCH. Made by Adrian Tafoya.

## Description
BK Picker is a fast Windows utility:

- Eyedropper with loupe and a global shortcut (Alt+C)
- Copy HEX, modern HSL, OKLCH, and HEX+alpha
- History, favorites, and CSS/JSON export
- Complementary, analogous, and triadic palettes
- Tailwind, Material, CSS named, and Bootstrap matches
- WCAG AA/AAA contrast vs white and black
- Sample from file, URL, drag-and-drop, or paste

BK Picker works locally on your PC. It does not upload screenshots.
